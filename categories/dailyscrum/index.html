    Daily Scrum & Ticket Burning

    Daily Work Report.

    업무량은 Ticket(T) 단위로 기록한다.

    • 1T ≈ 여유 있게 집중했을 때 약 30분 분량의 작업
    • Daily Pace ≈ 16T
    • Weekly Target = 80T
    • 100T 초과분은 해당 주의 기록으로만 남기고 다음 주로 이월하지 않는다.
    • T는 실제 소요시간이 아니라 작업량(workload) 기준으로 기록한다.

    Metrics

    각 DWR에서는 아래 항목을 기록한다.

    • Done — 완료한 Ticket
    • Weekly — 이번 주 누적 Ticket
    • Focus — 실제 집중 작업 시간
    • Work — 휴식/전환을 포함한 전체 업무 시간
    • Issues — 진행을 방해한 이슈 / 당일 발생한 이슈
    • Next — 다음에 처리할 작업
